Simulate Formula One from 1989 or 1991 to 2026 via virtual dice rolling. 
Send feedback/bug reports to F1DiceSimulator@gmail.com or via facebook.com/F1DiceSimulator

Features:
* Driver movement between seasons to allow play from 1989/1991 - 2026
* Team rivalries and driver/team relationships
* Historical tracking and all-time rankings
* Data export options
